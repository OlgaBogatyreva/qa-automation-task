# QA Automation Task

Проект содержит автотесты для проверки форм авторизации и поиска сотрудников.

## Стек технологий
* **Java 17**
* **Selenide**
* **JUnit 5** 
* **Maven** 

##  Структура проекта
* `src/test/java/pages` — Page Objects (классы страниц `LoginPage`, `SearchPage`).
* `src/test/java/tests` — Тестовые классы (`LoginTest`, `SearchTest`).
* `src/test/resources/pages/index.html` — Тестируемая HTML-страница.

## Как запустить тесты

Локально: 
   ```bash
   mvn clean test 
   ```

##  Покрытие тестами

В ходе выполнения задания были реализованы следующие проверки:

### Форма авторизации (`LoginTest`):
* Успешный вход с валидными данными.
* Проверка ошибки при неверном формате Email.
* Проверка ошибки при неверном пароле (валидный формат Email).

### Форма поиска (`SearchTest`):
* Поиск сотрудника по точному имени.
* Проверка отображения `empty state` (когда ничего не найдено).
* Проверка сброса всех фильтров по кнопке «Сбросить».
* **Попарное тестирование :** с помощью параметризованных тестов проверены комбинации фильтров.
* Проверка выхода из системы (Logout).
